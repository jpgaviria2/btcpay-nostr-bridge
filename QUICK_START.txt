╠═══════════════════════════════════════════════════════════════╣
║  STEP 1: Add Nostr Private Key                               ║
╠═══════════════════════════════════════════════════════════════╣
║                                                               ║
║  nano /home/btcpay/btcpay-nostr-bridge/.env                  ║
║                                                               ║
║  Find line: NOSTR_PRIVATE_KEY=YOUR_PRIVATE_KEY_HERE          ║
║  Replace with your actual nsec key                           ║
║                                                               ║
╠═══════════════════════════════════════════════════════════════╣
║  STEP 2: Configure BTCPay Webhook                            ║
╠═══════════════════════════════════════════════════════════════╣
║                                                               ║
║  1. Go to: https://anmore.cash                               ║
║  2. Store Settings → Webhooks → Create Webhook               ║
║                                                               ║
║     Payload URL: https://anmore.cash/btcpay-webhook          ║
║     Events:      ☑ InvoiceSettled                            ║
║     Secret:      Click "Generate" and copy it                ║
║     Content:     application/json                            ║
║                                                               ║
║  3. Add secret to .env file:                                 ║
║     BTCPAY_WEBHOOK_SECRET=<paste_secret_here>                ║
║                                                               ║
╠═══════════════════════════════════════════════════════════════╣
║  STEP 3: Start the Service                                   ║
╠═══════════════════════════════════════════════════════════════╣
║                                                               ║
║  sudo systemctl enable btcpay-nostr-bridge                   ║
║  sudo systemctl start btcpay-nostr-bridge                    ║
║  sudo systemctl status btcpay-nostr-bridge                   ║
║                                                               ║
║  Watch logs:                                                 ║
║  sudo journalctl -u btcpay-nostr-bridge -f                   ║
║                                                               ║
